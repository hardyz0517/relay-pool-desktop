# Relay Pool Desktop v0.3.3

v0.3.3 is an architecture scale upgrade release candidate. It keeps the local OpenAI-compatible endpoint and desktop workflows stable while tightening IPC contracts, command ownership, runtime lifecycle boundaries, provider connectivity behavior, and release qualification gates.

## Highlights

- Adds stricter generated IPC, command registry, ACL, runtime contract and architecture boundary checks.
- Splits large command and feature surfaces into smaller owner modules with focused public entry points.
- Narrows provider, collector, remote-key, connectivity and page-controller ownership so new work has a smaller modification surface.
- Improves station key connectivity qualification for OpenAI-compatible providers and records an authenticated live provider probe separately from deterministic fixtures.
- Keeps release verification on one shared entrypoint for PR and release paths, including release-version checks, locked Rust builds, artifact policy and bundle scans.
- Supports the existing passwordless Tauri updater signing key path used by this project while preserving non-interactive release bundling.

## Before upgrading

- Fully exit Relay Pool Desktop from the tray before installing or updating.
- Keep a backup of the local data directory before upgrading from an older technical-preview build.
- Do not run multiple Relay Pool Desktop versions against the same local data directory at the same time.

## Known boundaries

- This release remains qualified primarily for Windows x64.
- Signed bundle, install, supported upgrade, relaunch and single-instance qualification are part of the final release gate and must be performed on the exact tagged release revision.
- Provider live qualification uses an approved temporary OpenAI-compatible endpoint and records only redacted evidence.
