# Relay Pool Desktop v0.4.1

v0.4.1 is a maintenance release focused on release reliability, production dead-code cleanup, and routing workspace contract coverage.

## Highlights

- Removes high-confidence stale production code paths from Tauri services, adapters, routing, monitoring, persistence, and operational fact surfaces.
- Adds a production dead-code inventory gate so release builds fail on new unaudited dead code instead of silently accumulating old interfaces.
- Tightens release verification entrypoints for tagged GitHub releases, including separate prebundle and postbundle phases.
- Strengthens local routing UI/query synchronization contracts with additional focused tests.
- Refreshes generated IPC and TypeScript bridge contracts after the backend cleanup.

## Before upgrading

- Fully exit Relay Pool Desktop from the tray before installing or updating.
- Keep a backup of the local data directory before upgrading from an older technical-preview build.
- Do not run multiple Relay Pool Desktop versions against the same local data directory at the same time.

## Known boundaries

- This release remains qualified primarily for Windows x64.
- The app is still a local desktop tool, not a hosted relay service or team management system.
- Remaining warning noise is tracked as follow-up work when it is test-only, third-party/toolchain-originated, or intentionally documented.
- API keys, cookies, local databases, logs, and local configuration files must remain outside tracked project files.
