# Relay Pool Desktop v0.4.6

v0.4.6 聚焦中转站官方渠道状态采集、站点详情可观测性和变更中心活动视图，同时完成 schema 42 数据迁移与发布前验证契约收口。

## 主要更新

- 新增 Sub2API 官方渠道状态采集：通过单次渠道监视器列表请求读取官方发布状态，支持完整、部分、空结果、授权失败、接口不支持和异常响应等状态。
- 新增独立的官方渠道状态事实层，保存采集来源、端点版本、渠道、模型样本、延迟、缺失状态和新鲜度；不与主动渠道监控或密钥健康事实混用。
- 在站点详情页新增官方渠道状态工作区，展示渠道当前结果、最近样本趋势、缺失渠道和安全的错误状态；新增采集间隔设置与手动采集入口。
- 扩展 Station Collector 调度和 IPC 契约，补齐 Rust DTO、TypeScript 绑定、命令注册、权限清单以及跨层测试夹具。
- 变更中心新增“活动”视图；远程分组缺失改为信息型变更，不再作为持续活动告警，并修正分页游标在活动事件与历史变更混排时的行为。
- 数据库升级到 schema 42，新增官方渠道状态表及分组缺失信息变更迁移；便携迁移目录校验改为基于实际 SQLite schema 验证。
- 更新架构契约、发布检查和 README，补充官方渠道状态功能边界与升级说明。

## 升级前

- 升级或安装前，请先从系统托盘完全退出 Relay Pool Desktop。
- 升级前请备份本地数据目录。
- 请勿让多个 Relay Pool Desktop 版本同时操作同一个本地数据目录。

## 已知边界

- 本版本仍主要面向 Windows x64 认证。
- 官方渠道状态目前支持 Sub2API；其他中转站适配器会显示为未支持或未采集。
- 官方渠道状态是中转站发布信息的只读采集，不代表本地主动探测结果，也不直接替代路由健康判断。
- 应用是本地桌面工具，不是托管中转服务或团队管理系统。
- API key、cookie、本地数据库、日志和本地配置文件必须保持在受跟踪项目文件之外。
