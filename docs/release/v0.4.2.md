# Relay Pool Desktop v0.4.2

v0.4.2 improves intelligent routing, operational health visibility, and local routing workspace usability.

## Highlights

- Refines routing admission, candidate planning, capacity handling, affinity, and runtime dispatch behavior.
- Adds operational fact projections and routing health IPC reads for more accurate diagnostics.
- Improves channel, dashboard, station, and local routing status views with focused candidate and key-health coverage.
- Refreshes generated command and TypeScript bridge contracts.

## Before upgrading

- Fully exit Relay Pool Desktop from the tray before installing or updating.
- Keep a backup of the local data directory before upgrading.
- Do not run multiple Relay Pool Desktop versions against the same local data directory at the same time.

## Known boundaries

- This release remains qualified primarily for Windows x64.
- The app is a local desktop tool, not a hosted relay service or team management system.
- API keys, cookies, local databases, logs, and local configuration files must remain outside tracked project files.
