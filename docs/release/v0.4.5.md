# Relay Pool Desktop v0.4.5

v0.4.5 聚焦上游错误分类与重试闭环、告警路由与采集器事件整合，以及仪表盘和运营工作流的体验打磨。

## 主要更新

- 在请求日志中记录上游 HTTP 状态码，并在变更中心新增采集器事件，方便排查上游与采集异常。
- 加固上游错误路由生命周期：收紧错误分类与重试边界，提交后不重放、未知传输阶段保持 fail-closed，并补齐持久化边界与回归测试。
- 加固代理路由生命周期，移除旧版 monitor run 持久化，统一收敛到 V2 监控事实。
- 扩展价格与告警活动契约，对齐定价、站点管理与路由工作区的前后端契约，并刷新生成的 IPC 与 TypeScript 桥接绑定。
- 改进变更中心与请求日志视图，修复日志分页控件在窄窗口下的可见性问题。
- 打磨仪表盘与运营工作流：优化仪表盘布局、密钥健康摘要、本地路由状态以及站点、通道、新增供应商等管理界面。
- 整理项目规范与记录，对齐架构与验证工具链。

## 升级前

- 升级或安装前，请先从系统托盘完全退出 Relay Pool Desktop。
- 升级前请备份本地数据目录。
- 请勿让多个 Relay Pool Desktop 版本同时操作同一个本地数据目录。

## 已知边界

- 本版本仍主要面向 Windows x64 认证。
- 应用是本地桌面工具，不是托管中转服务或团队管理系统。
- API key、cookie、本地数据库、日志和本地配置文件必须保持在受跟踪项目文件之外。
