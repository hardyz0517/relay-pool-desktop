# Relay Pool Desktop v0.4.4

v0.4.4 improves change-center alerting defaults, incident cleanup, and local persistence behavior.

## Highlights

- Adds scoped incident cleanup for active, unread, or resolved alerting records.
- Adds persistent read state and mark-read actions for informational change records.
- Adds a default-on setting that removes recovered alerts atomically, with restart-safe cleanup for residual resolved records.
- Refines alerting policy defaults for audit changes, invalid keys, collector failures, and recovery notifications.
- Improves change-center, dashboard, and station detail workflows, including opening a station website from its detail view.
- Separates persistence read and write pools so writes remain available while read snapshots are busy.
- Refreshes the generated Tauri command registry and TypeScript bridge contracts.
- Removes the read-only pre-V2 monitor-run command and table after historical rows were backfilled into V2 monitoring facts.

## Before upgrading

- Fully exit Relay Pool Desktop from the tray before installing or updating.
- Keep a backup of the local data directory before upgrading.
- Do not run multiple Relay Pool Desktop versions against the same local data directory at the same time.

## Known boundaries

- This release remains qualified primarily for Windows x64.
- The app is a local desktop tool, not a hosted relay service or team management system.
- API keys, cookies, local databases, logs, and local configuration files must remain outside tracked project files.
