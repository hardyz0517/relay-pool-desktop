# Relay Pool Desktop v0.4.0

v0.4.0 is a desktop workflow and routing operations release. It keeps the local OpenAI-compatible entrypoint focused while improving station discovery, key monitoring, routing diagnostics, upgrade recovery, and release qualification.

## Highlights

- Streamlines station setup, key discovery, and key pool monitoring so daily desktop workflows need fewer manual choices.
- Improves NewAPI/Sub2API-compatible collector boundaries, station balance normalization, and routing status diagnostics.
- Hardens schema upgrade recovery and records the development reset/reimport boundary for technical-preview data.
- Tightens routing operational read models, self-checks, and local qualification evidence.
- Updates the built-in model base pricing catalog from the pinned Sub2API source.
- Refines channel health summaries so isolated failures or degraded samples do not overstate current unavailability.

## Before upgrading

- Fully exit Relay Pool Desktop from the tray before installing or updating.
- Keep a backup of the local data directory before upgrading from an older technical-preview build.
- Do not run multiple Relay Pool Desktop versions against the same local data directory at the same time.

## Known boundaries

- This release remains qualified primarily for Windows x64.
- The app is still a local desktop tool, not a hosted relay service or team management system.
- API keys, cookies, local databases, logs, and local configuration files must remain outside tracked project files.
