# 文档归档

本目录保存已完成阶段、被后续方案取代或不再指导当前实现的工程记录，仅用于追溯历史。开发和评审应从 [`../README.md`](../README.md) 返回当前规范与当前工程入口。

## 分类

- [`plans/`](plans/)：已经完成、停止或被后续计划取代的一次性实施计划。
- [`specs/`](specs/)：已经落地、被替代或仅保留设计背景的技术快照。
- [`audits/`](audits/)：已结束阶段的基线、进度和验收记录。
- [`early-phase-plans/`](early-phase-plans/)：P1-P8 早期阶段计划。

## 使用约定

- 归档内容不作为当前实现依据，也不应继续维护实现细节。
- 需要恢复某项工作时，应新建当前提案或计划，并链接相关归档，而不是直接“复活”旧计划。
- 当前自动化直接读取的 JSON 清单、边界清单和仍在使用的资格记录保留在 [`../audits/`](../audits/)；不要仅因日期较早就移动它们。
- ADR 记录已接受架构决策，默认保留在 [`../adrs/`](../adrs/)；决策被替代时通过新 ADR 建立替代关系。
